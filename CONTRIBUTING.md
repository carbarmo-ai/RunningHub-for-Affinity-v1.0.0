# Contributing

Contributions, bug reports, and documentation improvements are welcome.

Before submitting changes:
1. Open an issue describing the change, with no credentials or personal image data.
2. Keep the integration compatible with both RunningHub AI Apps and registered ComfyUI workflows.
3. Preserve image dimensions during transfer; do not introduce automatic resizing of submitted or returned full-resolution images.
4. Keep public-facing strings, documentation, and file names in English.
5. Include clear reproduction steps and tests where possible.
6. Respect third-party licenses and retain required attribution.

Contributions are intended to be distributed under **GPL-3.0-only**. Contributors must have the rights necessary to submit their work. No contributor license agreement is currently required.
